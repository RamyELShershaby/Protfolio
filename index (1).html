06 — PROJECTS

Selected work

Segmented Enterprise Network Redesign

PROBLEM

A flat lab topology with no VLAN separation left broadcast traffic unbounded and increased the blast radius of any single compromised host.

APPROACH

Redesigned the topology with VLAN segmentation, STP for loop prevention, EtherChannel for link redundancy, and OSPF for inter-VLAN routing.

OUTCOME

Reduced broadcast domain size, documented a redundant-link failover path, and produced a repeatable segmentation template.

Lab simulation · CCNA coursework

Multi-Tier AWS E-Commerce Infrastructure

PROBLEM

An e-commerce workload needed a highly available, fault-tolerant, and secure AWS environment — without relying on manual, error-prone provisioning.

APPROACH

Built the full stack as Infrastructure as Code with AWS CloudFormation: a custom VPC across 2 Availability Zones with 6 subnets (public, private app, and isolated database tiers), dual NAT Gateways for outbound redundancy, an Auto Scaling Group behind an Application Load Balancer with step and target-tracking scaling, shared EFS storage, and defense-in-depth via security groups, NACLs, and least-privilege IAM with SSM access.

OUTCOME

Verified traffic distribution across AZs via the ALB, confirmed real-time EFS synchronization between instances, and validated auto-scaling by triggering CloudWatch alarms under CPU stress testing.
